## Who we are

**ZaZa International** is an independent technology team building software products and engineering prototypes. We turn complex requirements into working systems, explore new ideas, and share our engineering work through code.

Our current work spans conversational systems, machine learning, and data-driven digital platforms. We care about practical engineering: clear architecture, reproducible experiments, honest documentation, and software that can be tested beyond a presentation.

## Selected projects

### [Voice Assistant](https://github.com/ZaZa-International/voice-assistant)

**A voice assistant for clinic reception workflows.**

A system designed to handle common appointment journeys: booking, rescheduling, cancellation, appointment status, doctor schedules, reminders, and escalation to a human operator. The repository includes the backend dialogue flow, telephony integration, and a local speech pipeline.

- Python · FastAPI · Docker · Asterisk
- Local speech-to-text and text-to-speech components
- Structured dialogue outcomes and integration with a medical information system

[Explore the repository →](https://github.com/ZaZa-International/voice-assistant) · [Open the project demo](https://voice.zazainternational.ru)

---

### [Kaspian Digital Forum](https://github.com/ZaZa-International/kaspian-digital-forum)

**A digital twin prototype for multimodal logistics across the Caspian region.**

An interactive logistics workspace exploring route planning, shipment visibility, operational risks, document workflows, and scenario-based decision support for the North–South transport corridor.

- Interactive 2D/3D map and logistics workspace
- Route comparison, risk analysis, and shipment timelines
- Clear distinction between live data, estimates, and simulated demo data

[Explore the repository →](https://github.com/ZaZa-International/kaspian-digital-forum) · [Open the project demo](https://kdf.zazainternational.ru)
